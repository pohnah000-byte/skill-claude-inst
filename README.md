# Мои плагины для Claude — на русском

Все плагины и навыки из моего Claude в одном репозитории. Описания каждого плагина и каждого навыка переведены на русский: по ним видно, что делает навык, и по ним же Claude решает, когда его включать. Внутренние инструкции навыков оставлены как были — это технический текст для самого Claude, он одинаково работает на любом языке.

Плюс новый навык **«Монтаж по ссылке»** — присылаете ссылку или файл, получаете готовые Reels/Shorts в своём стиле.

## Как установить

1. Создайте на GitHub репозиторий (лучше **приватный** — внутри чужой код) и загрузите в него всё содержимое этой папки. В корне должны лежать `README.md`, папки `.claude-plugin/` и `plugins/`.
2. Добавьте репозиторий в Claude как маркетплейс плагинов из GitHub (формат: `ваш-логин/имя-репозитория`). В Claude Code это команда `/plugin marketplace add ваш-логин/имя-репозитория`.
3. Установите нужные плагины из этого маркетплейса.

### Важно перед установкой

- **Удалите оригиналы.** Если оставить и оригинальные плагины, и эти копии, каждый навык окажется в списке дважды. Навыки, которые вы загружали zip-файлами (ScrapeCreators, ig-*, vibe-wise-learn), тоже удалите: они теперь входят в «Мои навыки».
- **Войдите в сервисы заново.** Плагины с подключением к сервисам (Creative Claw, CutPro, Adobe, Figma, Abracadabrax, ManyMotions) после установки попросят снова войти в аккаунт.
- **Обновления не придут сами.** Это копии: когда авторы выпустят новые версии, их нужно перенести вручную.

## Монтаж по ссылке

Напишите Claude, например: «Смонтируй рилс из этого видео» и приложите ссылку или файл.

1. Ролик скачивается по ссылке. Если площадка не отдаёт видео без входа (часто так с YouTube), навык предложит CutPro или попросит прислать файл.
2. Речь расшифровывается в текст с таймкодами.
3. Claude предлагает лучшие моменты с хуками, вы утверждаете.
4. Собирается вертикальное видео: без пауз, с субтитрами и выделенным словом, хуком на экране, логотипом, музыкой и финальным призывом, громкость выровнена под соцсети.
5. Вы получаете MP4, обложку и подпись к посту.

При первом запуске Claude задаст несколько вопросов о вашем стиле и выдаст файл `stil-montazha.md`. Положите его в файлы проекта — дальше всё будет «как обычно» без вопросов.

Скрипты можно запускать и на своём компьютере (нужны Python 3 и ffmpeg):

```bash
pip install yt-dlp faster-whisper
python3 plugins/moi-navyki/skills/montazh-po-ssylke/scripts/transcribe.py видео.mp4
python3 plugins/moi-navyki/skills/montazh-po-ssylke/scripts/montage.py example > plan.json
python3 plugins/moi-navyki/skills/montazh-po-ssylke/scripts/montage.py render plan.json
```
