# Монтаж по ссылке

Цель — из длинного или сырого видео получить готовые короткие ролики в стиле автора, не заставляя его разбираться в монтаже. Говори с пользователем по-русски и простыми словами, без терминов ffmpeg.

Монтируй только видео пользователя или те, на которые у него есть права. Если ссылка ведёт на чужой ролик, спроси в одном предложении, есть ли разрешение автора, и не скрывай авторство.

Скрипты лежат рядом: `scripts/montage.py` (монтаж) и `scripts/transcribe.py` (расшифровка). Перед первым запуском:

```bash
pip install --break-system-packages yt-dlp faster-whisper
```

Нужен ffmpeg (`which ffmpeg`). Работай в отдельной папке под каждый проект, исходники пользователя не изменяй.

## 1. Получить исходник

- **Файл приложен** — копируй в рабочую папку.
- **Прямая ссылка на файл** (`.mp4`, публичный Яндекс Диск, Google Drive, Dropbox и т. п.) — скачай `curl -L` или `yt-dlp`.
- **Ссылка на площадку** (YouTube, VK, Rutube, TikTok, Instagram…) — попробуй `yt-dlp --no-playlist -f "bv*[height<=1080]+ba/b" --merge-output-format mp4`. Если площадка требует входа, капчу или «подтвердите, что вы не бот», **не обходи защиту**: не подставляй куки, логины и пароли. Вместо этого предложи на выбор:
  1. **CutPro**, если он подключён: он сам берёт видео по ссылке YouTube, Twitch, Kick и TikTok, нарезает и может опубликовать. Действуй по навыку `cutpro`: сначала бесплатный `analyze_video`, назови стоимость и жди согласия.
  2. Прислать файл в чат (скачать своё видео из приложения или из студии площадки).
  3. Если к разговору подключён компьютер пользователя с командной строкой, скачать ролик там — только с его согласия.

## 2. Профиль стиля «под меня»

Ищи файл `stil-montazha.md`: в файлах проекта, среди вложений или в памяти о пользователе. Если он есть, используй его и не задавай повторных вопросов.

Если файла нет, проведи короткую настройку через AskUserQuestion (по 1–4 вопроса за раз, с вариантами): площадки и формат, длина роликов, темп (сколько резать паузы), вид субтитров (цвет, выделение слов, крупно в центре или внизу), хук на экране, музыка, логотип или ник, финальный призыв. Заполни шаблон `stil-montazha-shablon.md` и отдай пользователю файл `stil-montazha.md` с советом положить его в файлы проекта, чтобы в следующий раз всё было «как обычно».

Если человек пишет «делай сам», «без вопросов» — бери значения по умолчанию из шаблона и скажи одной строкой, что выбрал.

## 3. Разобрать видео

```bash
python3 scripts/montage.py analyze исходник.mp4          # длительность, паузы, смены сцен
python3 scripts/transcribe.py исходник.mp4 --model small  # исходник.srt / .json / .txt
```

- Модель `small` — хороший баланс для русского. Для ролика длиннее 20 минут предупреди, что расшифровка займёт время, и предложи CutPro или `--model base`.
- Если в видео нет речи (музыка, влог без слов), выбирай моменты по сменам сцен и громкости.
- Если у пользователя уже есть субтитры (`.srt` из CapCut, YouTube и т. п.), используй их и не расшифровывай заново.

## 4. Выбрать моменты

По расшифровке найди отрезки, которые работают как самостоятельный ролик:

- в первые 1–3 секунды есть крючок: вопрос, спорное утверждение, цифра, «ошибка», обещание результата;
- законченная мысль без ссылок на «как я говорила выше»;
- 15–60 секунд (или длина из профиля стиля);
- можно склеить 2–3 куска из разных мест, если вместе они дают одну историю.

Покажи пользователю таблицу: № · таймкоды · о чём · текст хука на экран · почему зайдёт. Жди «да» или правок. Если пользователь заранее сказал «выбери сам», сразу переходи к монтажу и напиши, какие моменты выбрал.

## 5. Смонтировать

Составь план для каждого ролика (пример: `python3 scripts/montage.py example`) и запусти:

```bash
python3 scripts/montage.py render plan.json
```

Что можно задать в плане:

| Поле | Что делает |
|---|---|
| `segments` | отрезки из исходника в нужном порядке |
| `remove_silence` | вырезает паузы; темп «динамичный» ≈ `min_silence: 0.35`, «спокойный» ≈ `0.8` |
| `format`, `reframe` | `9:16` / `1:1` / `4:5` / `16:9` / `original`; `blur` — размытый фон, `crop` — кадрирование по центру |
| `subtitles` | SRT из расшифровки; время пересчитывается после вырезок автоматически; `words_per_chunk` 2–4 для Reels, `highlight` — цвет главного слова |
| `hook` | крупный текст в первые секунды |
| `logo`, `music`, `end_card` | логотип, музыка с приглушением под голос, финальный призыв |
| `speed` | ускорение 1.05–1.15 оживляет медленную речь |
| `cover` | кадр-обложка PNG |

Громкость выравнивается под соцсети (−14 LUFS) автоматически.

## 6. Проверить перед отправкой

Вытащи 3 кадра (начало с хуком, середина с субтитрами, конец) и посмотри их сам через Read: текст не обрезан, субтитры не закрывают лицо, логотип на месте. Убедись, что длительность соответствует плану. Только потом отправляй.

## 7. Отдать результат

- Отправь MP4 и обложку через SendUserFile.
- Предложи подпись к посту: навык `ig-caption`, если он есть, или напиши сам — первая строка-крючок, один призыв.
- Одной строкой предложи следующий шаг: ещё варианты хука, другие моменты или публикация через CutPro.

## Другие инструменты

- **CutPro** — длинные видео и стримы, автоматический подбор клипов, публикация в TikTok, Instagram и YouTube.
- **Creative Claw** (`creativeclaw-edit-media`, `creativeclaw-create-reels`) — монтаж и нарезка на их сервере, если подключён.
- **Adobe Quick Cut** (`adobe-edit-quick-cut`) — быстрая нарезка хайлайтов без точных таймкодов.

Используй их, когда пользователь просит или когда локальный монтаж не справляется (очень длинное видео, нужна публикация).
