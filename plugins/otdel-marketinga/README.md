# Отдел маркетинга «Полный вперёд»

Целый отдел маркетинга из шести ИИ-сотрудников. Ставите задачу одной фразой — отдел сам делает бриф, распределяет работу и сдаёт готовые тексты, сценарии и планы, а не советы.

Имена рифмуются, чтобы запомнить с первого раза:

> **Рулёт** рулит, **Звездочёт** считает, **Постомёт** расставляет, **Буквоплёт** пишет, **Вертолёт** снимает, **Банкомёт** продаёт.

## Команда

| Сотрудник | Почему так зовут | Что делает |
|---|---|---|
| Рулёт | рулит отделом | Руководитель и стратег: бриф, цель, приоритеты, план, итоговая сводка |
| Звездочёт | считает «звёзды» — лайки, охваты, конкурентов | Аналитик: портрет ЦА, боли, конкуренты, тренды, разбор статистики |
| Постомёт | строчит посты по графику, как пулемёт | SMM: контент-план по Threads, Instagram, TikTok, Telegram и ВКонтакте |
| Буквоплёт | плетёт тексты из букв | Копирайтер: посты, ветки, подписи, прогревы, офферы, тексты бота |
| Вертолёт | снимает вертикалки | Сценарист: рилс и TikTok, хуки, раскадровки, карусели, промпты для нейросетей |
| Банкомёт | превращает подписчиков в деньги | Продажи: офферы, цены, лид-магниты, воронки, объявления, метрики |

## Как пользоваться

Пишите обычными словами:

- «Отдел маркетинга, запусти продажи гайда за 390 ₽» — работает весь отдел.
- «Буквоплёт, напиши ветку для Threads про бесплатные нейросети» — работает один сотрудник.
- «Постомёт, план на неделю» — планёрка.
- «Звездочёт, разбери статистику» + скриншот — разбор результатов.

Отдел сдаёт итог в одном формате: главное в 3 строки → готовые материалы → что сделать сегодня → как поймём, что сработало.

## Как установить

**claude.ai и приложение Claude.** Скачайте [otdel-marketinga.zip](https://github.com/pohnah000-byte/skill-claude-inst/raw/main/skills-zip/otdel-marketinga.zip) и загрузите в **Настройки → Возможности → Навыки**. Здесь сотрудники работают внутри одного чата по очереди.

**Claude Code.** Здесь каждый сотрудник — отдельный агент, и они работают параллельно:

```
/plugin marketplace add pohnah000-byte/skill-claude-inst
/plugin install otdel-marketinga@ru-plugins
```

## Как настроить под свой бизнес

В конце файла `skills/otdel-marketinga/SKILL.md` есть раздел «Контекст бизнеса по умолчанию». Сейчас там пример — блог pro_pravda про ИИ. Замените его на свой продукт, площадки и цены, и отдел будет работать под вас без лишних вопросов.

## Что внутри

- `skills/otdel-marketinga/SKILL.md` — правила отдела: роли, режимы работы, полный цикл от брифа до сдачи, карточки сотрудников и контекст бизнеса.
- `agents/` — шесть агентов для Claude Code: `rulyot`, `zvezdochyot`, `postomyot`, `bukvoplyot`, `vertolyot`, `bankomyot`.
